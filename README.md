# Tahqiq

An AI-assisted search app for the Quran and authentic Hadith. Ask a question,
get a cited answer drawn directly from primary sources, cross-referenced across
collections.

## Structure

- `backend/` — FastAPI service (retrieval + generation API)
- `mobile/` — React Native app
- `admin-dashboard/` — Next.js admin/review tooling

## Setup

Setup instructions per service are in each subfolder's own README (to be added
as each is scaffolded).
